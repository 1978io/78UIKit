Figure rows & split bars ._78-figure-row · ._78-split-bar

Two shapes for numbers that belong together. A figure row is one fact in parts — entry / target / stop, plan / actual / variance — each part carrying a tone as a colored left edge. A split bar is one whole divided into named segments. Both use the same ._78-tone-* classes as the charts above, so a figure and the bar beside it agree on color.

Notifications — which one?

Three components, one rule. Ship the rule, not just the widgets: pick by what the user has to do, not by how it looks.

ComponentUse forBehaviorAPI
Modal Needs acknowledgement — errors, confirms Blocks. Requires a click. _78.modal.open/confirm/alert
Toast Informational — “Saved”, “Copied” Auto-dismisses. Never blocks. _78.notify()
Inline alert Tied to a region — form errors, empty states Sits in the layout. Persists. ._78-alert (CSS)

Modal native <dialog> · showModal()

Opened with showModal(), never show() — that is what gives the top layer, the ::backdrop, the focus trap and Escape. Every opener returns a Promise; dismissing (Escape, backdrop, ×) resolves null/ false.

The close button is a <form method="dialog">, so it would close even with JavaScript disabled.

Toasts _78.notify()

Stack in the corner, auto-dismiss (4s; errors 6s), never block. duration: 0 makes one sticky — it then only leaves by its close button.

Segmented control ._78-seg · _78.seg

A joined run of buttons where exactly one is active — a range toggle, a chart type, a units switch. It owns a value, not a panel: that is what separates it from the segmented tabs above (bound to panels) and from ._78-btn-group (spaced, every button its own action). Mounted as a radiogroup with roving tabindex, so ←/→ (and Home/End) move between the options and step over disabled ones. Every change fires _78:segchange.

A styled <details>: the native marker is replaced with a chevron that rotates on open, and everything else — keyboard, screen readers, find-in-page — stays the browser’s. No JS. This is the progressive “show the numbers behind this” pattern.
