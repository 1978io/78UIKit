Three third-party libraries, zero forks, one theme. Flip the toggle — the table, the calendar and the charts all follow. Tabulator and FullCalendar come along for free (their colors resolve to kit tokens at runtime); the chart is canvas, so js/adapters/chartjs.js re-reads the tokens on _78:themechange and updates every live chart.

Tabulator 6.x · CSS adapter

Header, rows, hover, selection, sort arrows, header filters, pagination and popups all map to tokens. Click a row to select it, sort a column, page through — every state is themed. Try the Country header filter and double-click a Rating cell to edit it.

FullCalendar 7.x core · CSS adapter

v7 ships hashed class names (fc-classic-dl1…), so its palette custom properties are the entire theming surface — and that is all the adapter touches: --fc-classic-* remapped onto kit tokens. Toolbar, grid lines, today's cell, events, the list view and the focus ring all follow. v6 stays supported by a legacy block in the same file

Chart.js 4.x · JS adapter

Canvas can't read CSS variables, so Chart.defaults gets the tokens pushed into it — and because defaults are read at construction, every live chart is updated on each theme switch. The series colors come from _78.adapters.chartjs.palette(n): accent first, then the semantic tokens.

Including them

Adapters are opt-in — they are not part of kit.css. Include only the ones you use, always after the library.

<!-- kit -->
<link rel="stylesheet" href="/78UIKit/css/kit.css">
<script src="/78UIKit/js/_78.js"></script>

<!-- library, then its adapter -->
<link rel="stylesheet" href="…/tabulator.min.css">
<link rel="stylesheet" href="/78UIKit/css/adapters/tabulator.css">

<link rel="stylesheet" href="…/fullcalendar@7/skeleton.css">
<link rel="stylesheet" href="…/fullcalendar@7/themes/classic/theme.css">
<link rel="stylesheet" href="…/fullcalendar@7/themes/classic/palette.css">
<link rel="stylesheet" href="/78UIKit/css/adapters/fullcalendar.css">
<script src="…/fullcalendar@7/all/global.min.js"></script>
<script src="…/fullcalendar@7/themes/classic/global.js"></script>

<script src="…/chart.umd.js"></script>
<script src="/78UIKit/js/adapters/chartjs.js"></script>

Nothing is vendored here — bring your own version of each library. The CSS adapters are version-sensitive (class names move between majors); the version each was built against is noted at the top of the file.
